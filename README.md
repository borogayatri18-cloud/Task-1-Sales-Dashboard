# Global Superstore Sales Power BI Dashboard

## 📊 Project Overview

This project is a Power BI dashboard created as part of Internship Task 1.

The dashboard analyzes Global Superstore sales data and presents key business insights through interactive visualizations. It provides an overview of sales, profit, orders, regional performance, product categories, customer performance, and monthly sales trends.

## 🎯 Objectives

- Analyze overall sales performance
- Track total sales, profit, and orders
- Compare sales performance across different regions
- Analyze sales by product category
- Identify the top 10 customers based on sales
- Understand monthly sales trends
- Provide interactive filtering for better data exploration

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📈 Key Performance Indicators

- *Total Sales:* 13M
- *Total Profit:* 1.47M
- *Total Orders:* 25.035K

## 📊 Dashboard Visualizations

### Sales by Region
A bar chart showing sales performance across different regions.

### Sales by Category
A pie chart showing the distribution of sales among:
- Technology
- Furniture
- Office Supplies

### Top 10 Customers by Sales
A bar chart identifying the top 10 customers based on their total sales.

### Monthly Sales Trend
A line chart showing how sales change throughout the year.

### Interactive Filters
The dashboard includes filters for:
- Order Date
- Region

These filters allow users to interactively explore the sales data.
